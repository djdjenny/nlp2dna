# Влияние токенизации на представления ДНК в языковых моделях

## Цель

Исследовать, как выбор токенизации влияет на качество представлений ДНК, получаемых языковыми моделями, обученными с нуля.

> Насколько геометрия эмбеддингов и downstream-результатов определяется выбором токенизации?

---

# Гипотезы

1) Качество будет распределено как bpe>6-mer>3-mer>nucleotide
2) Токенизация влияет не только на качество downstream-задач, но и на геометрию пространства эмбеддингов.
3) При одинаковом числе параметров модели BPE позволит получить более информативные представления последовательностей.

## Геномы

Для обучения используются референсные геномы пяти организмов:
- t2t human

## Формирование корпуса

Для каждого генома:

- случайным образом выбираются 100 000 фрагментов;
- длина каждого фрагмента — 512 bp;
- фрагменты равномерно выбираются из разных хромосом (или контигов);
- по возможности избегаются сильные перекрытия между окнами.

Итоговый корпус:
- 500 000 последовательностей;
- около 256 млн нуклеотидов.

# Токенизации

## 1. Nucleotide-level

Каждый символ является отдельным токеном.

Словарь: A, T, G, C, N

## 2. 3-mer

Последовательность из трех нуклеотидов (масштаб кодона). 

Размер словаря: 64

## 3. 6-mer

Последовательность из шести нуклеотидов (использовался в dnabert).

Размер словаря: 4096

## 4. BPE

Взять готовый или натренировать (тк корпус специфичный)
Размер словаря - 4096

# Модель

Для всех экспериментов используется одна и та же архитектура BERT-подобного энкодера.

Возможные параметры модели:

| Размер | Конфиг                   | Параметры |
| ------ | ------------------------ | --------: |
| Tiny   | 256 / 4 heads / 6 layers |       ~6M |
| Small  | 384 / 6 heads / 6 layers |      ~13M |
| Medium | 512 / 8 heads / 6 layers |      ~22M |
Оценка времени на small - до 10 часов на l4 на одну токенизацию, это предпочтительный вариант

# Ожидаемые результаты

Предполагаемый порядок качества:

BPE ≥ 6-mer > 3-mer > nucleotide-level.

Ожидается, что:

- увеличение размера токена улучшит качество представлений;
- BPE позволит эффективнее кодировать повторяющиеся мотивы;
- различия проявятся как в GENEB, так и в структуре пространства эмбеддингов;
- модели с более информативной токенизацией будут демонстрировать лучшие результаты в probing-задачах.

# Ограничения

### Одновременно меняется несколько факторов

При изменении токенизации изменяются:

- размер словаря;
- длина последовательности в токенах;
- распределение токенов;
- эффективный контекст.


### Ограниченный объем данных

Используемый корпус значительно меньше корпусов, применяемых при обучении современных моделей. Использование только пяти организмов может ограничивать обобщающую способность полученных выводов.
