# nlp2dna


## Цель работы

Определить, как влияет **способ представления ДНК** на перформанс предобученных NLP моделей.
_опционально_ - определить, как влияет дообучение эмбеддингов на nucleotide level представлении на

## Проверяемые гипотезы

1. Среди различных представлений ДНК некоторые лучше согласуются с исходным пространством текстовых эмбеддингов.
2. Минимальная адаптация, затрагивающая только представления нуклеотидов, приводит к улучшению качества на геномных задачах.

Если улучшение достигается без изменения трансформера, то часть полезной структуры для обработки ДНК уже присутствует в архитектуре и пространстве признаков.

## Объект исследования

Предобученные текстовые модели (BGE-small-en-v1.5 или E5-small-v2).
Модели не модифицируются - не меняется архитектура, словарь, токенизатор.

ДНК подаётся как текст, который разбивается стандартным tokenizer модели.

## Представления ДНК

Для каждого окна генома строятся текстовые представления:
### 1. Nucleotide-level

Символы без группировки:
A C G T A C G T
### 2. k-mer representation
- k = 3
- k = 6

### 3. BPE representation

- BPE обучается на корпусе человеческого генома (T2T v2)
- vocab size: 5000, инициализация с A, T, G, C
- далее используется как текстовая сегментация последовательности

## Часть 1: Zero-shot evaluation (готовность NLP к ДНК)

Каждое представление преобразуется в embedding через модель.
Далее оценивается:
### 1. GENEB performance

### 2. Geometric structure / разделимость классов
#### intra / inter class косинусное расстояние
- расстояние внутри биологических классов
- расстояние между классами
#### umap визуализация с разметкой по классам

#### силуэт(?)

### 3. Representation stability
  Сравнение представлений одного и того же региона:

- nucleotide vs k-mer vs BPE
- cosine similarity между представлениями одного и того же региона


## Часть 2: Embedding-only adaptation

Модель фиксирована, обучается только embedding matrix. Обучение с помощью MLM подхода на T2T v2 (окно размера 512). Только на нуклеотидном уровне.

Измеряется:
- изменение GENEB score
- изменение intra/inter distance ratio

## Ключевые метрики
1) Изменение geneb performance при смене представления
2) Изменение расстояния между эмбеддингами одного и того же региона при смене представления
3) Прирост geneb performance на нуклеотидном представлении
4) Изменение расстояния между эмбеддингами до и после дообучения

Что позволит ответить на вопросы
- насколько эмбеддинги "универсальны" в своем применении
- какая форма представления ДНК лучше подходит под эту задачу
- что дает лучший прирост к перформансу - дообучение или выбор токенизации

## Потенциальные проблемы и недостатки постановки

1. Не совсем честное сравнение представлений. Например, 3-mer и BPE-представления не становятся отдельными токенами для модели, а дополнительно разбиваются её собственным BPE-токенизатором. В результате сравниваются не столько сами представления ДНК, сколько их взаимодействие с конкретным токенизатором.
->  BPE может оказаться малоосмысленным

2. GENEB может оказаться недостаточно чувствительным.
3. Сложности с ограничением метрик для определения разделимости классов (какое значение "слабо разделимы", какое "сильно разделены"?).
4. Слабая биологическая интерпретация.
5. Ограниченность 1 моделью и человеческим геномом.
